# PowerPoint-файл

В репозитории добавлен генератор настоящего редактируемого `.pptx`.

## Создание файла

```bash
npm install
npm run build
```

После этого появится файл `molodezhny-eko-patrul-porta.pptx`.

Слайд выполнен в формате 16:9: светлый минималистичный дизайн, карточки, инфографика, морская визуальная метафора, ЦУР 8 и ЦУР 17. В презентации задан плавный переход Fade; при необходимости дополнительные появления объектов можно включить через PowerPoint → Анимации.
