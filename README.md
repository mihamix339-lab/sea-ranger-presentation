# Презентация: Молодёжный эко-патруль порта

Готовый однослайдовый файл с анимациями и адаптивным светлым дизайном.

## Как открыть

Откройте `index.html` в браузере на весь экран. Для показа используйте полноэкранный режим (F11).

Файл работает автономно и не требует установки зависимостей или подключения к интернету.
